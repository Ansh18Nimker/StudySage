# StudySage 📚

StudySage is a web-based learning platform designed to help students access educational resources, manage study materials, and improve learning productivity through an intuitive dashboard experience.

## Features

- Secure user authentication
- Student dashboard
- Resource management system
- Search functionality
- Responsive user interface
- Session-based access control
- Cloud deployment

## Tech Stack

- Flask
- SQLAlchemy
- HTML
- CSS
- JavaScript
- Vercel

## Key Highlights

- Built a full-stack educational web application using Flask.
- Implemented user authentication and session management.
- Designed database models using SQLAlchemy ORM.
- Developed a responsive dashboard for resource access and management.
- Deployed the application on Vercel.
